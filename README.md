# Space-Time Studio｜时空可视化视频生成器

本地运行的固定机位视频时空可视化工具。阶段 1 核心、阶段 2 单视频导出和阶段 3 串行批处理已实现：均匀时间采样、按镜头估计背景、主体透明蒙版、完整画面对照、Three.js 交互旋转、确定性相机动画、JSON 参数预设，以及本机 FFmpeg H.264 MP4 导出。

## 环境

- macOS / Apple Silicon 或 Intel Mac
- Node.js 20.19+ 或 22.12+
- Python 3.10+
- FFmpeg（包含 `ffmpeg` 与 `ffprobe`）
- Chrome / Chromium，需启用 WebGL

脚本只检查本机软件并在项目内创建 Python 虚拟环境，不会修改系统 Python、安装 Homebrew 或更改系统配置。

## 安装与启动

在项目根目录运行：

```bash
./scripts/setup_mac.sh
./scripts/start_mac.sh
```

然后打开 <http://127.0.0.1:5173>。停止服务请在终端按 `Ctrl+C`。API 只监听 `127.0.0.1`。

## 使用

1. 选择 MP4、MOV 或 M4V 视频（最大 500 MB，最长 10 分钟）。导入后可在侧栏播放本地原片。
2. 播放到合适片段的入点和出点，分别点击“设为开始”“设为结束”；也可直接输入秒数。建议选取 5～10 秒固定机位片段，避免跨越切镜。
3. 选择 5、10 或 15 FPS 和背景模型。默认“固定背景”使用时间中位数差分；缓慢变化或周期性动态背景可试“动态背景 MOG2”。选好后点击“提取主体并构建 3D 轨迹”。
4. 鼠标左键旋转、滚轮缩放、右键平移。也可播放/暂停/循环“侧向掠过”“环绕”或“时间轴推进”相机动画，使用进度条定位镜头；调节阈值后再次构建以更新蒙版。
5. “完整画面”用于对照；在“三维渲染方式”中可选“卡片堆叠”或“整体三维体”。前者保留原有逐帧平面并可调时间间距，后者将全部采样帧打包为 3D 纹理、按画面高度归一化时间深度，再用体积光线步进渲染。透明度、参考平面和网格可直接调整。
6. 在预览上方保存或加载 JSON 参数预设；在导出面板选择 9:16 / 16:9 与 720p / 1080p，导出可取消并可从页面下载。

### 批量处理

1. 在批量面板一次选择多个视频。任务在本机按队列串行处理，当前任务完成后自动开始下一个。
2. 可为每条任务单独设置裁剪范围、采样率、差分参数、轨迹模式、相机预设、画幅和导出尺寸。
3. 失败任务可单独重试；失败不会阻断后续任务。可取消当前任务或暂停队列，之后再继续。
4. 队列状态与参数保存在当前浏览器的本地存储中；刷新或重启服务后，未完成任务会恢复为待处理，可继续运行。已生成 MP4 可通过页面链接重新下载。
5. 可导出 JSON 任务清单，记录任务状态、参数、输出文件名及失败原因。

## 当前限制

- 背景差分适用于固定机位、静态背景；系统会隔离明显硬切镜头，并尝试对齐置信度高的轻微全局抖动。大面积动态背景或无法稳定匹配的镜头仍会影响蒙版并显示提示。
- MOG2 是动态背景备选算法，不保证适用于所有视频；长时间停留的主体可能逐渐被模型吸收，处理后请对照完整帧模式。
- 最多采样 300 帧（15 FPS 可处理 20 秒）；界面从后端读取实际上限。预览帧宽度限制为 640 像素。估算纹理内存显示在页面下方。正式导出逐帧渲染 720p 或 1080p；视频不含音频。
- 整体三维体模式使用 WebGL 2 的 3D 纹理，并将最长边缩放到 768 像素以限制显存；较长或高分辨率素材的纹理构建和逐像素步进会比卡片模式更耗时。该路径目前通过生产构建检查，浏览器实际渲染和导出画质仍需验证。
- 背景差分适用于固定镜头、静态背景；真实人物/复杂背景素材和 MacBook Air M5 / 24 GB 长时负载仍需单独验证。
- 视频与处理中间帧暂存在项目 `tmp/`，生成的 MP4 保存在 `outputs/`；二者都只在本机处理。
- 批量队列元数据保存在当前浏览器，不是跨设备或多浏览器的服务端任务数据库；视频源文件与中间帧仍由本机服务管理。
- 浏览器运行需 WebGL；当前验证目标为 Chrome / Chromium。
